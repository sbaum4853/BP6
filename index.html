Wiring an ESP32 to an L298N with Two DC Motors

A 12 V battery pack powers the motors through the L298N driver. The L298N's onboard regulator powers the ESP32. The ESP32 runs both motors forward and then backward at full speed.

Parts

  • ESP32 dev board (DevKit V1 / DevKitC)
  • L298N dual H-bridge module (red board, black heatsink)
  • 2 × DC gear motors (6–12 V)
  • 12 V battery pack (e.g. 8 × AA)
  • Female-to-female or female-to-male jumper wires
  • Small screwdriver for the screw terminals

How power flows

  • 12 V goes into the L298N and drives the motors.
  • The L298N's regulator makes 5 V, which feeds the ESP32's VIN pin.
  • All grounds are tied together: battery, L298N, and ESP32.
  • The ESP32's 3.3 V signals tell the L298N which way to spin each motor.
Before you wire anything: keep the battery pack disconnected until every wire is in place and checked. Never connect 12 V to any ESP32 pin. The ESP32 only ever gets 5 V (on VIN) or 3.3 V.

3. Jumpers on the L298N

KEEP ON5V-EN jumper (next to the power terminal)
This turns on the onboard 5 V regulator so the +5V terminal outputs 5 V for the ESP32. Leave it on for any supply up to 12 V.
REMOVEENA and ENB jumpers (the little caps on the enable pins)
Pull them off so the ESP32 controls the enable pins. Use the pin closest to the board edge; that's the actual ENA/ENB input. The other pin is just 5 V.
Shortcut: because this sketch only runs at full speed, you could leave the ENA/ENB jumpers on and skip those two wires, since the jumpers hold the motors enabled. Wiring them to the ESP32 means you're already set up for PWM speed control later.

4. How the L298N chooses direction

ENAIN1IN2Motor A does…
HIGHHIGHLOWForward, full speed
HIGHLOWHIGHBackward, full speed
HIGHLOWLOWCoast to a stop
HIGHHIGHHIGHBrake (quick stop)
LOWanyanyOff (coast)

Motor B works the same way with ENB, IN3, and IN4.

5. The code (Arduino IDE)

Install the ESP32 boards package in the Arduino IDE (Boards Manager → search "esp32" by Espressif) and select ESP32 Dev Module. The sketch runs both motors forward for 2 seconds, pauses, runs them backward for 2 seconds, pauses, and repeats.

// ESP32 + L298N: two DC motors, forward and backward at full speed

// ---- Motor A (left) ----
const int ENA = 14;   // enable A
const int IN1 = 27;
const int IN2 = 26;

// ---- Motor B (right) ----
const int IN3 = 25;
const int IN4 = 33;
const int ENB = 32;   // enable B

const int RUN_TIME   = 2000;  // ms each direction
const int PAUSE_TIME = 500;   // ms stopped between directions

void setup() {
  Serial.begin(115200);

  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENB, OUTPUT);

  stopMotors();

  // Enable pins held HIGH = full speed, always
  digitalWrite(ENA, HIGH);
  digitalWrite(ENB, HIGH);

  Serial.println("Motors ready");
}

void forward() {
  digitalWrite(IN1, HIGH);  digitalWrite(IN2, LOW);   // Motor A forward
  digitalWrite(IN3, HIGH);  digitalWrite(IN4, LOW);   // Motor B forward
}

void backward() {
  digitalWrite(IN1, LOW);   digitalWrite(IN2, HIGH);  // Motor A backward
  digitalWrite(IN3, LOW);   digitalWrite(IN4, HIGH);  // Motor B backward
}

void stopMotors() {
  digitalWrite(IN1, LOW);   digitalWrite(IN2, LOW);   // coast
  digitalWrite(IN3, LOW);   digitalWrite(IN4, LOW);
}

void loop() {
  Serial.println("Forward");
  forward();
  delay(RUN_TIME);

  Serial.println("Stop");
  stopMotors();
  delay(PAUSE_TIME);   // let the motors spin down before reversing

  Serial.println("Backward");
  backward();
  delay(RUN_TIME);

  Serial.println("Stop");
  stopMotors();
  delay(PAUSE_TIME);
}
Why the pause? Slamming a spinning motor straight into reverse pulls a big current spike. That spike can sag the 5 V line and reset the ESP32. A half-second stop between directions avoids it.

6. Upload and test, in this order

  1. Unplug the battery and disconnect the orange 5 V wire from VIN. That keeps two power sources from feeding the ESP32 at the same time.
  2. Plug the ESP32 into your computer by USB and upload the sketch. (Some boards need you to hold BOOT when "Connecting…" appears.)
  3. Unplug the USB cable.
  4. Reconnect the orange wire to VIN, then connect the battery pack.
  5. The wheels should spin forward for 2 s, stop, spin backward for 2 s, and repeat. Prop the robot up so the wheels are off the table.
Want to watch Serial Monitor while it runs? Leave the orange 5 V wire disconnected and keep USB plugged in. The ESP32 runs from USB, the motors run from the battery, and the black ground wire still ties them together.

7. Troubleshooting

SymptomLikely cause / fix
Nothing spins at allMissing common ground between the ESP32 and L298N. Or the battery is flat. Or the screw terminals aren't tight (tug each wire).
One motor spins the wrong waySwap that motor's two wires at its OUT terminals. No code change needed.
Only one motor worksCheck that motor's EN and IN wires, and that its EN jumper isn't half-seated.
ESP32 resets or the LED flickers when motors start or reverseVoltage sag. Use fresh batteries, keep the stop pause, and put a 470–1000 µF capacitor across the L298N's 12 V and GND terminals.
ESP32 doesn't power on from the battery5V-EN jumper missing. Or the orange wire went to 3V3 instead of VIN/5V.
Motors weaker than expectedNormal: the L298N drops about 2 V, so a 12 V pack gives roughly 10 V at the motors. It also gets warm, which is what the heatsink is for.
Upload failsHold BOOT during "Connecting…". Use a data USB cable, not a charge-only one. Pick the right COM/serial port.
Battery note: eight fresh AAs or a 12 V NiMH pack is fine. A 3S LiPo reads up to 12.6 V when full. That works for the motors, but it's at the top of the onboard 5 V regulator's range. Above 12 V, remove the 5V-EN jumper and power the ESP32 from a separate 5 V source (still sharing ground).

Next step: speed control

Because ENA and ENB are on ESP32 pins, you can replace the digitalWrite(ENA, HIGH) lines with PWM later. On ESP32 Arduino core 3.x that's analogWrite(ENA, 180); (0–255) for roughly 70% speed, with no rewiring.
